# Bekannte Probleme

Folgende Probleme sind bekannt. An der Behebung wird gearbeitet.

## Debian – Anzeige „virtualisiert“

Debian wird durch `/dev/vhost-vsock` als „virtualisiert“ angezeigt.

## Debian – Lockscreen

Unter Debian (Gnome/Wayland) kann im abgesicherten Modus der Lockscreen nicht genutzt werden.

## WLAN-Info

Unter macOS kann die WLAN-Information (SSID) nicht abgerufen werden; das ist eine Einschränkung der macOS-Berechtigungen für außerhalb des App Stores verteilte Apps.
Unter Windows tritt dieses Verhalten ebenfalls auf, wenn die Standortberechtigung nicht erteilt wurde (Positionsdienste in den Datenschutzeinstellungen aktivieren).
